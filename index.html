Plugins

Plugins are small add-ons that run in a locked sandbox. They cannot make network requests, and each one gets only the permissions you tick. A malicious plugin could still try to send data out by redirecting its own frame, so install only code you wrote or fully trust.

Plugin guide

A plugin is an HTML page. Inside it, a global CVS object is available:

await CVS.get('jd' | 'cv' | 'resume')   needs Read
await CVS.ai('your prompt')            needs Use AI, returns text
await CVS.set('jd' | 'cv', 'text')     needs Change boxes
await CVS.note('title', 'text')        needs Save notes
await CVS.toast('message')

Calls without the ticked permission fail. Network requests are blocked inside plugins. Plugins are included in your backups and cloud sync.
